# Tick Cursor Cycle

Cycles the mouse cursor colour on each game tick, with 1-6 configurable tick slots and user-selectable colour and opacity for each slot.

## Features

- Supports 1-6 configurable tick slots
- Lets the user choose a colour and opacity for each slot
- Uses a bundled cursor image so it works across platforms
- Falls back to a polygon cursor shape if the bundled image cannot be loaded
